# DigitaHinos Clarinete

Visualizador MIDI com digitação de clarinete (E3–Dó7).

## Partitura com digitação
A partitura (ao vivo, janela de partitura e PDF) mostra, sob cada nota, o desenho dos furos e chaves do clarinete (preto = fechado/apertado).

## Repetições e casas 1ª/2ª/3ª
A ordem de execução respeita os sinais de repetição e as casas (1.2. e 3.), inclusive a última nota antes do coro (ex.: hino 61).
